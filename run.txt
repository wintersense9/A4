Assessment 4 Git/GitHub 操作步骤
==================================
依据：31263-32004 IGDev Assessment 4.pdf（Git Repository 占 10%，3.5 分）

分支结构要求
------------
- main 分支 + dev 分支 + 每完成一个 grade band 至少一个 feature 分支
- dev 从 main 分出；feature 从 dev 分出（同一 band 的后续 feature 可从第一个 feature 分出）
- 每个 feature 分支要有多条 commit；band 完成后合并回 dev
- 提交前：dev 合并回 main，并停留在 main 上（让 marker 直接看到完成品）
- 仓库必须连接远程服务器（GitHub / BitBucket），.git 里有 remote 引用即可，无需分享账号
- 分支和 commit 数量要与达到的 band 成比例
- 一次只做一个分支/feature/band，避免合并冲突；经常 commit + push
- 注意：Git/电脑/Unity 崩溃不批延期（dangitgit.com 可查急救方法）


第 0 步：初始化仓库并连接远程（一次性）
--------------------------------
0. 命令必须在 Unity 项目根目录执行（即 Assets、ProjectSettings 所在的那层）！
   Desktop\A4 文件夹里只有 PDF，不是 Unity 工程，在那里面执行会报
   "fatal: not a git repository"
1. 项目还没有 .git 的话，先初始化：

   cd Unity项目根目录路径
   git init

2. 确保有 .gitignore（Unity 项目必须忽略 Library/ Temp/ 等目录），没有就先创建
3. 在 GitHub 上新建一个空仓库（不要勾选 README/.gitignore 初始化）
4. 关联远程仓库：

   git remote add origin https://github.com/wintersense9/A4.git
   git add .
   git commit -m "Initial commit"
   git push -u origin main


第 1 步：建 dev 分支（从 main 分出）
--------------------------------
   git checkout main
   git checkout -b dev
   git push -u origin dev


第 2 步：每个 band 一个 feature 分支（从 dev 分出）
--------------------------------
band 与建议分支名对应表：
   20% Z  补 Assessment 3            -> Feature-Catchup
   30% Z  开始界面 StartScene        -> Feature-StartScreen
   40% Z  游戏内 UI 外观             -> Feature-InGameUI
   55% P  PacStudent/Cherry 移动     -> Feature-Movement
   70% D  碰撞/UI 功能/高分存档      -> Feature-Collisions
   85% HD Ghost 移动与 AI            -> Feature-GhostAI
   100% HD 设计创新                  -> Feature-Innovation

每个 band 的工作循环（一次只做一个分支）：

   git checkout dev
   git checkout -b Feature-StartScreen

   # ...开发过程中多次小 commit...
   git add .
   git commit -m "Add StartScene with animated border"
   git push -u origin Feature-StartScreen

   # band 完成后合并回 dev
   git checkout dev
   git merge --no-ff Feature-StartScreen
   git push

然后重复：下一个 band 再从 dev 分出新 feature 分支。


第 3 步：全部完成、提交前（关键）
--------------------------------
   git checkout main
   git merge --no-ff dev
   git push
   git branch        # 确认当前在 main（显示 * main），再打包


提交注意事项
------------
1. 交付物：整个 Unity 项目文件夹打成 zip（必须是 .zip），
   命名：studentNumber_A4_Project.zip
2. 打包前先删除 Unity 项目里的 Library 文件夹
3. zip 里必须包含 .git 文件夹和 .gitignore（marker 靠 .git 验证 remote）
   - .git 是隐藏文件夹：资源管理器打包需开启"显示隐藏项目"；
     或用 PowerShell Compress-Archive（默认包含隐藏文件）
4. 声明文件：studentNumber_A4_Declaration.txt 在 Canvas 单独入口提交


出问题怎么办
------------
- 合并搞砸了：git reset --hard 回到之前的 commit
- 电脑坏了：换电脑 git clone 远程仓库继续做
- 其他问题：https://dangitgit.com/
